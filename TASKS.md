Static site, no build/lint/test tooling, so verification means reading the markup plus loading the pages in a browser. Serve them over HTTP (`python -m http.server`) rather than opening `file://` URLs — the browser tooling refuses `file://`. Note the browser caches `script.js` aggressively across reloads; if a JS change appears not to have taken effect, cache-bust the script src before concluding anything (this produced a false pass on 2026-09-06).
